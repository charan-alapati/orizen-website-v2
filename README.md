# OriZen - Modern Web Platform 🚀

A state-of-the-art, high-converting web application for **OriZen (Center for Foreign Languages & Overseas Consultancy)** built with **React 18, Vite, Tailwind CSS, and Lucide Icons**.

---

---

## ✨ Features & Architecture

1. **Frosted Glass Navigation Bar:** Sticky header with active pill indicator, responsive mobile slide-out drawer, and instant consultation triggers.
2. **High-Impact Hero Section:** Dynamic gradient headlines, live stats counter (500+ students, 98.6% visa rate, 0€ tuition), and trust badges.
3. **Interactive Eligibility & Pathway Quiz:** 3-step wizard that recommends the exact German/European track for the student's background and budget.
4. **Foreign Language Academy Hub:** Tabbed support for German (A1–C2), French, Italian, and IELTS/English with an interactive CEFR level visualizer.
5. **Study Abroad European Hub:** Country cards (Germany 🇩🇪, Austria 🇦🇹, Switzerland 🇨🇭, Latvia 🇱🇻, France 🇫🇷, Netherlands 🇳🇱) with a deep-dive modal detailing tuition fees, top universities, and the 6-Step Visa Roadmap.
6. **Interactive Cost & Living Calculator:** Computes annual tuition, blocked account deposit (€11,208/yr), living costs, and part-time student job earnings offset.
7. **Job Opportunities & Anerkennung Guide:** Pathways for Healthcare/Nursing, IT/Tech, and Engineering in Germany with step-by-step qualification recognition.
8. **Real Student Testimonials & University Marquee:** Authentic reviews with destination universities and 5-star ratings.
9. **Interactive FAQ Accordion:** Filterable with live search for APS, Blocked Accounts, and Goethe Exams.
10. **Center Contact & Google Maps Integration:** Physical Vijayawada office address, working hours, interactive inquiry form, and WhatsApp routing.
11. **Smart AI Assistant Chatbot:** Multi-branch assistant answering queries with 1-click WhatsApp escalation.
12. **Book 1-on-1 Free Counseling Modal:** Multi-step appointment scheduler for In-Person or Online Zoom counseling.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory, ready to deploy to any web hosting (Vercel, Netlify, cPanel, Hostinger, GitHub Pages, Apache/Nginx).

### 4. Preview Production Build
```bash
npm run preview
```
